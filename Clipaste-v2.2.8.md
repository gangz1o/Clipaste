## ✨ 本次更新

### 🛠 修复与体验优化

- 修复链接预览可能完整下载大文件、造成异常后台流量的问题。
- 为网页与站点图标抓取增加严格流量上限、响应类型校验和重复请求合并。
- “默认模式”下不再自动请求链接元数据，同时保留本地语法高亮行为。

---

## ✨ What's New

### 🛠 Fixes & Improvements

- Fixed an issue where link previews could download entire large files and cause excessive background data usage.
- Added strict transfer limits, response type validation, and in-flight request coalescing for page and favicon metadata.
- Link metadata is no longer fetched automatically in Default Mode, while local syntax highlighting remains unchanged.
